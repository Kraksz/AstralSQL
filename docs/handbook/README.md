# Astral SQL handbook

A focused, local-first SQL workspace with a Rust core. Connect directly to SQLite,
PostgreSQL, MySQL, and MariaDB from the desktop app.

1. [Install Astral](installation.md).
2. [Run your first query](querying.md).
3. [Connect a remote server](connections.md).
4. Find an answer in the [FAQ](faq.md).

The browser playground runs SQLite locally. It cannot open raw TCP connections to
remote database servers. Use the desktop app for MySQL, MariaDB, and PostgreSQL.

Source: [Kraksz/AstralSQL](https://github.com/Kraksz/AstralSQL).
